# Versions de Takt Studio

La première ligne de chaque version s'affiche dans le bandeau de mise à jour de l'appli.

## 0.2.0

Première version installable : installateur Windows, mises à jour intégrées et quatre langages.

- Installateur Windows sans droits administrateur, fichiers `.takt` associés, raccourcis, désinstallation.
- Mises à jour depuis les Releases GitHub, vérifiées par SHA-256.
- Langages CONT (ladder), SCL, GRAPH (SFC) et BASIC, tous avec temps de cycle garanti.
- Disposition d'atelier : ruban, gestion de projet, boîte à outils, fenêtre d'état, barre d'état.
- Simulateur PLCSIM intégré, visualisation en ligne, tables de forçage.
- Projets récents et thème mémorisés.
